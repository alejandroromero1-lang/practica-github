# practica-github

## Propósito
Aprender a crear y gestionar un repositorio en GitHub: subir archivos, documentar con un README y consultar el historial de versiones.

## Descripción
Repositorio de práctica para la asignatura de Programación y Robótica. Contiene un programa sencillo en Python (`hola_mundo.py`) que muestra un saludo por pantalla y del que se han subido dos versiones para comprobar el historial de commits.
